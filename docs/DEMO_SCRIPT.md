## 第一部分：项目结构简介（30 秒）

| 画面 | 旁白 |
|------|------|
| 在 IDE 中展开项目文件树，逐层高亮 | 项目基于 Python 和 Streamlit 构建，使用 Claude API 作为 AI 引擎。核心模块分为四层：`src/novel_parser.py` 负责章节解析，`src/ai_analyzer.py` 是 AI 三阶段 Pipeline 的核心，`src/script_builder.py` 负责剧本组装和校验，`src/yaml_generator.py` 负责 YAML 格式输出。`prompts/` 目录下存放着三个 Prompt 模板，`docs/` 下是 YAML Schema 设计文档。 |

| 点击「📄 YAML 剧本」子标签 | 最后看最重要的——YAML 剧本输出。 |

| 高亮 `type: action` 片段 | action 类型——场景环境和动作描述，使用现在时态。 |

## 录制提示

1. **声音**：用正常语速，不要太快。旁白读出来大约需要 5-6 分钟，加上操作延迟总长约 7-8 分钟
2. **鼠标**：操作时鼠标移动要稳，点击前停顿 0.5 秒让观众看清位置
3. **高亮**：可以用鼠标画圈或使用屏幕放大工具（Windows 自带 Win++）突出重点
4. **剪辑**：如果某段操作卡住了（比如 AI 转换等待时间太长），可以在后期把等待部分加速 2-3 倍，加上"AI 转换中，已加速"字幕
5. **上传**：导出为 MP4 格式，上传到 B 站后，把视频链接填入 README 最开头的预留位置
