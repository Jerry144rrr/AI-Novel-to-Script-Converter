## 剧本格式说明
你需要将小说叙事文本转换为以下三种剧本元素：

1. **action（动作/场景描述）**：描述场景环境、人物动作、氛围等，使用现在时态
2. **dialogue（对话）**：角色的台词，标注说话人、情绪、必要时标注括号内的动作指示
3. **transition（转场）**：场景切换标记，如"切至"、"淡入"、"淡出"等

对于每句对话，请从原文推断角色的情绪状态（紧张/平静/愤怒/喜悦/悲伤/恐惧/疑惑/冷漠）。

## 输出要求
请严格按照以下 JSON 格式输出剧本内容：
{
  "content": [
    {
      "type": "action",
      "text": "场景描述文本，使用现在时态"
    },
    {
      "type": "dialogue",
      "character": "角色名",
      "line": "台词内容",
      "parenthetical": "(动作指示，如无可省略)",
      "emotion": "情绪"
    },
    {
      "type": "transition",
      "effect": "切至"
    }
  ]
}

## 重要规则
- JSON 字符串值中如果有双引号，必须用反斜杠转义（如：她说\"你好\"）
- 对话内容中的引号请使用中文引号「」或单引号'
- 保留原文所有对话，不要增删台词
- 将原文的叙述性描述精简为剧本式的动作描述
- 对话顺序必须与原文一致
- 角色名必须与提供的角色信息中的名称一致
- 情绪标注要准确反映上下文
- 如果原文是章节结尾，最后一个元素添加 transition
